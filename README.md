# Floquet–Kitaev Model Project 

Python simulations developed for my MSci project investigating the
periodically driven Kitaev honeycomb model.

We Floquet band structures, topological invariants,
and spatial localisation, including simulations of time-vortex
(spacetime) defects.

This repository contains numerical calculations investigating these
questions through:

- Floquet band-structure calculations.
- Chern and winding-number calculations.
- Local density of states and spatial-localisation plots.
- Time-vortex and multiple-vortex simulations.
